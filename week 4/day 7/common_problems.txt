Question 15 / 20

Two studies have the same standard deviation:

Study A sample size = 25
Study B sample size = 400

Which study should have the smaller standard error?

A or B?

#B 
#standard error = standard deviation / √sample size



Both studies have the same standard deviation.

So we can call that unknown standard deviation S.

Then:

Study A:
SE = S / √25
SE = S / 5


Study B:
SE = S / √400
SE = S / 20

Since:

S / 20 < S / 5

Study B has the smaller standard error.

So the question was only asking you to compare them, not calculate the exact standard error.

If I wanted you to calculate an actual number, I would need to give you something like:

standard deviation = 10
sample size = 400

Then:

SE = 10 / √400
SE = 0.5

So you were right to question it: you cannot calculate the exact standard error unless the standard deviation is given or you have the data to calculate it.
