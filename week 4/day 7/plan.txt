# FINAL WEEK 4 CHECK

# By the end I should understand:

# Mean / median = center

# Variance / standard deviation = spread

# Probability = how likely something is

# Conditional probability = probability given new information

# Bayes = update probability using evidence

# Distribution = how possible values/probabilities are arranged

# Sampling variability = different samples give different results

# Standard error = how much sample means tend to vary

# Bootstrap = repeatedly resample existing data with replacement

# Confidence interval = range showing uncertainty around an estimate

# Correlation = two variables tend to change together

# Correlation does NOT automatically mean causation

# Confounding = a third variable influences the relationship

# Effect size = how large the difference or relationship actually is


# WEEK 4 MAIN LESSON

# A score calculated from a sample is an estimate,
# not permanent proof.

# Small samples can produce unstable results.

# We should measure uncertainty before trusting ML results.
